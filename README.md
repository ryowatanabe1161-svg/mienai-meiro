# みえない迷路 〜ふーさんと まほうのしるし〜

▶ **遊ぶ：https://ryowatanabe1161-svg.github.io/mienai-meiro/**

ブラウザだけで遊べる、2〜4人用の **見えない壁の迷路・記憶ボードゲーム（オンライン版）** です。
夜の森の地下にある見えない壁の迷路を、見習いまほうつかいになって進み、「まほうのしるし」を集めます。CPU は **ふーさん🐻**。

> 既存の市販ゲームの「6×6の見えない迷路・サイコロ・壁に当たるとスタートへ・先に5つ集める」という遊び方（ルールの仕組み）を参考にした、オリジナル作品です。タイトル・テーマ・絵・文章はすべて独自のものです。

## 遊び方
1. ホストが「部屋を作る」。4文字の部屋コード・招待URL・QRコードが出ます。友だちはURL／QRかコードで参加（2〜4人）。足りなければ「ふーさん🐻（CPU）」を追加（ふーさん、ふーさん🐻2…と番号つき）。
2. 6×6のマスのあいだ（すき間60か所）に **見えない壁** を置きます（公式：24枚／かんたん：19枚）。どのマスにもたどり着けることを毎回確認しています。
   - **ランダム（標準）**：ホストの端末が自動で置きます。
   - **みんなで決める**：くじで決めた人から順番に、盤のすき間をタップして1枚ずつ置きます（ふーさん🐻は自動）。「置いた壁 n / 24」のカウンターつき。置くと **たどり着けないマスができるすき間は置けません**（自分の番には赤い斜線で表示。タップすると「そこに置くと、たどり着けないマスが○つできてしまいます…」と表示し、そのマスが赤く点滅）。自分が置いた壁は **次の人が置くまで「↩ 取り消す」** ことができ、番が自分に戻ります。ホストは「🎲 残りをランダムで埋める」で一気に完成させられます。組み立て中の壁は全員に見えます。
   - **迷路を見せる時間**（なし／5秒／10秒（標準）／20秒）：ゲームの最初に全員が迷路を見られます。大きなカウントダウンが0になると壁はふわっと消え、そのあとは **だれにも見えません**（ホストの画面にも出ません）。
   - **ボードの回転**（なし／回転／回転＋反転）：壁が消えたあと、**地下の壁だけ** が90°ずつ1〜3回（向きもランダム）まわります。回転＋反転では半分の確率でさらに左右に裏返ります。回る向き・回数はアニメで全員に見えるので、よく数えて頭の中で迷路を回しましょう。
3. **自分の番**：サイコロ（1・2・2・3・3・4）をタップ → 出た目まで、矢印ボタンか隣のマスをタップして1マスずつ進む（曲がってOK・ななめNG）。「ここで止まる」で途中終了もOK。
4. **見えない壁にぶつかると**「ゴツン！」→ 玉がポトン（効果音つき）→ のこりの歩数はなし、自分のスタートの角に戻って次の人へ。
5. **しるし**：いま探しているしるしは1つだけ。そのマスに最初に着いた人がもらい、すぐ次のしるしが出ます（次のマスにだれかが立っていれば、その人がそのままゲット）。
6. 先に **5つ** 集めた人の勝ち。終了画面で **迷路の壁がすべて公開** されます（だれかがぶつかった壁は赤で表示）。

## ロビー設定（ホストのみ）
| 設定 | 選択肢 | 既定 |
|---|---|---|
| 見えない壁の数 | 24枚（公式）／19枚（公式のかんたん） | 24枚 |
| ぶつかった壁を表示 | なし（公式・おぼえるしかない）／あり（かんたん・赤い✕の印が残る） | なし |
| ふーさん🐻の記憶力 | やさしい（ときどき忘れる）／ふつう／つよい（見た壁を全部おぼえる） | ふつう |
| 壁の決め方 | ランダム（標準）／みんなで決める（順番に1枚ずつ） | ランダム |
| 迷路を見せる時間 | なし／5秒／10秒（標準）／20秒 | 10秒 |
| ボードの回転 | なし／回転（90°×1〜3回）／回転＋反転（裏返しもあり） | なし |

「ランダム」＋見せる時間「なし」のときは、壁をだれも見ないので回転は行いません（回しても意味がないため）。

### ボードの回転：何が回るのか
**回るのは地下の壁の配置だけ** で、しるしのマス・スタートの角・駒は動きません。見せる時間に覚えた「迷路の形」はそのままに、しるしや角との位置関係（向き）だけが変わるので、「形は覚えているのに、どっちが上だっけ？」という頭の体操になります。しるしや角まで一緒に回すと盤全体を回しただけと同じで、覚えた内容がそのまま使えてしまうため、この方式にしました。アニメでは回転前の壁の「影」が盤の下でまわり（向きの目印▲つき）、「左回り ↺ 2回目」のように向きと回数を表示し、最後に消えます。壁は内側のすき間にしかないので、90°回しても反転しても必ずすき間にぴったり収まり、どのマスにも行ける性質も変わりません。終了画面には回ったあとの本当の壁と「この迷路は最初に右回り↻に2回まわりました」が表示されます。

## ふーさん🐻（CPU）
- みんなに見えている情報（だれかが通れた道・だれかがぶつかった壁）だけを記憶して考えます。本当の壁の配置は見ません（単体テストで確認）。
- **見せる時間・迷路づくり・回転も人間と同じ条件**：覚えている割合は「記憶力 × 見た時間」（5秒より20秒のほうがよく覚える。組み立てを見ていたら長く見たのと同じ。自分で置いた壁はよく覚えている）。回転はアニメで見えた回数・向きを使いますが、やさしい（約50%）・ふつう（約15%）は **数え間違える** ことがあり、そのときは覚えた迷路を間違った向きで信じてしまいます（「…何回まわったか、わからなくなったクマ」）。つよいは回数を正しく数えます。プレイ中に自分の目で確かめた「通れた／ぶつかった」は、はじめの記憶より優先します。
- 記憶力に応じて覚えている確率が変わり、やさしいは時間がたつと忘れることもあります。おぼえている壁を避け、知らない道は少し慎重に、目標へ最短の道を探します。
- 「えいっ！クマ」「いたたっ…壁があったクマ！」「みつけたクマ〜！」などしゃべります。切断した人の代わりに「ふーさんに交代」もできます。

## 中断・再接続
- 迷路づくり・見せる時間・回転の途中でも、中断（ロビーへ）・ホストの再開・参加者の再接続ができます（見せる時間の途中でホストが再読み込みした場合は、再開時に残りの時間から続き、過ぎていれば次へ進みます）。
- ⋯メニュー：ホストは「中断してロビーに戻る」（確認あり・部屋コード／参加者／CPU／設定はそのまま）。参加者は「ロビーに戻りたい」をホストに伝える／「退出する」。
- 参加者は同じ端末なら「部屋に戻る」、別の端末でも同じニックネームで入れば元の席に戻れます。ホストは再読み込みしても「前回の部屋を再開する」で同じ迷路から続けられます。

## しくみ
- PeerJS（WebRTC）によるP2P。**ホストのブラウザが審判** で、壁の配置・しるしの山・CPUの判断をすべて持ちます。
- 参加者に送るのは「駒の位置・この手番の軌跡・しるし・サイコロの目」など全員に見えている情報だけ。**プレイ中は壁の配置を送りません**。
- **見せる時間・迷路づくりについて**：全員の画面に壁を表示するため、その間だけは参加者の端末も（回転前の）壁の配置を受け取ります。開発者ツールなどを使えば保存できてしまうのは、実物で「スマホで写真を撮る」のと同じで防げません（覚えるのはプレイヤーの良心におまかせ）。見せる時間が終わってプレイが始まると、**参加者の端末は受け取った壁のデータを消し**（受信記録・画面の状態とも）、以後のメッセージには壁は一切入りません。回転の向き・回数も、見せる時間中には送らず回転アニメの開始時に送ります。「ランダム」＋見せる時間「なし」なら、これまでどおり壁は終了まで一度も送られません。ぶつかった瞬間の演出（どこでぶつかったか）だけは、実物のゲームと同じく全員が見られます。「ぶつかった壁を表示：なし」のときは、ぶつかった壁の一覧も送りません。
- 音はWebAudioで合成（音声ファイルなし）。🔊ボタンでON/OFF。

## オンライン版の追加ルール
- ほかの人のスタートの角にも止まれません（戻る場所が必ず空いているように）。通りぬけはOK。
- 万一、のこり歩数で止まれる場所がまったくなくなったら、その手番のはじめのマスに戻ります（ほぼ起きません）。
- スタートプレイヤーは「いちばん最近道に迷った人」の代わりにくじ引き。
